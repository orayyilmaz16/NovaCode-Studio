# Aksiyon: Arayüz metinleri (8 dil)

## Geliştirici metinleri
`src/i18n/uiTextDev.ts` (hata ayıklama, LSP, terminal modu) `registerTexts` ile kaydolur; `TextKey` içinde `DevTextKey` vardır. Kullanan dosya `import './i18n/uiTextDev'` yapar; `scripts/brain.mjs` üç dosyayı da tarar.

## Kural
Kullanıcı arayüzüne eklenen **her metin 8 dilde**: `tr, en, de, ru, ar, es, fr, az`. Eksik dil kabul edilmez.

## Nasıl
1. `src/i18n/uiText.ts` içindeki `UI_TEXT` nesnesine anahtar ekle; her dil dolu olmalı.
2. Bileşende `t('anahtar')` kullan. Değişken gerekirse `{ad}` yer tutucusu + `.replace('{ad}', değer)`.
3. Sabit Türkçe string yazma. (Eski panellerde kalanlar bilinen borçtur; dokunulan satırlar taşınır.)
4. Arapça için metin yönü kısa tutulur; ikon + metin düzeni bozulmamalı.
5. Marka/teknik terimler (`commit`, `push`, `PR`, `Git`) çevrilmeyebilir.

## Doğrulama
`npm run brain:check` her anahtarın 8 dilde dolu olduğunu denetler. Üretim: önce Türkçe, sonra diğerleri; kısa, doğal, "sen" dili (marka sesi).
